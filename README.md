A sophisticated AI-powered financial intelligence platform for micro-business owners. Upload your transactions and the AI automatically categorizes them, forecasts cashflow, and delivers actionable business insights.

**🎯 Key Features:**
- 📊 Smart Dashboard with real-time financial statistics
- 🤖 AI-powered transaction classification and analysis
- 🔮 Intelligent cashflow forecasting using machine learning
- 💬 AI CFO chat assistant for financial advice
- 💡 Auto-generated business insights and recommendations
- 🎯 Goals & scenario planning
- 📤 CSV upload + manual transaction entry
- 📈 Business analytics and performance tracking

**🛠️ Tech Stack:**
- **Frontend:** Vite + Vanilla JavaScript + Chart.js (Vercel)
- **Backend:** FastAPI + Python 3.13 (Railway)
- **Database:** PostgreSQL + Supabase
- **AI Provider:** Groq API (LLM: gpt-oss-120b)

**💡 What Makes It Special:**
This project showcases practical AI/ML integration for real business problems. The LLM processes financial data and generates human-readable insights, combining natural language processing with financial analytics.

### ⚡ [Smart EV Charging Station Finder](https://github.com/M-Taha-Raza12/SmartEVCharginStationFinder)
**IoT & AI-Integrated Smart Charging Platform | ASP.NET Core, React, TypeScript, AI Recommendations**

A comprehensive full-stack platform for finding, booking, and managing electric vehicle charging stations with AI-powered recommendations and intelligent station discovery.

**🎯 Key Features:**
- 🗺️ Interactive Map with OpenStreetMap integration & real-time availability
- 📅 Smart booking system with flexible time slot reservations
- 🧠 AI-powered station recommendations based on location & budget
- ⭐ Favorites system & user ratings/reviews
- 💰 Wallet system for seamless payments
- 📊 Charging history & analytics dashboard
- 🔔 Real-time notifications
- ⚙️ Station management (for owners)
- 👥 Multi-role system (Client, Owner, Admin)

**🛠️ Tech Stack:**
- **Backend:** ASP.NET Core 10.0 + Entity Framework
- **Frontend:** React 19 + TypeScript + Vite
- **Database:** PostgreSQL (Supabase)
- **Authentication:** JWT
- **Maps:** Leaflet + OpenStreetMap
- **AI:** Groq API Integration for recommendations

**💡 What Makes It Special:**
This project demonstrates full-stack development with AI integration. The smart recommendation engine uses ML algorithms to suggest optimal charging stations based on user preferences, location, and pricing, improving user experience and charging efficiency.
