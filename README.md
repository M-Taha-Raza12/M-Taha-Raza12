A sophisticated AI-powered resume analysis platform that helps users improve their resumes with intelligent suggestions and job-market alignment.

**Features:**
- 📄 Resume parsing (PDF & TXT support)
- 🧠 AI-powered analysis with improvement suggestions
- 🎯 ATS keyword matching against job descriptions
- ✍️ AI-powered resume rewriting
- 🎤 Interview question generation
- 🔐 Supabase authentication & storage

**Tech Stack:**
- **Frontend:** React + Vite + React Router + Supabase Auth
- **Backend:** FastAPI + Python
- **Database:** Supabase (PostgreSQL + Storage)
- **AI Provider:** Groq API
